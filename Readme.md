# Focus Group Discussion (FGD) - Student Innovation Centre (SIC) UNUD

**Focus Group Discussion (FGD)** adalah kegiatan tahunan yang diselenggarakan oleh **Student Innovation Centre (SIC) Program Studi Informatika, Fakultas Matematika dan Ilmu Pengetahuan Alam (FMIPA), Universitas Udayana (Unud)**.

## 🎯 Tujuan Kegiatan
**Mengasah Berpikir Komputasional:** Membantu mahasiswa baru Informatika dalam melatih kemampuan *computational thinking*.
**Keterampilan Berdiskusi:** Melatih kemampuan komunikasi, kolaborasi, dan pemecahan masalah dalam kelompok.

## 📚 Materi Pembelajaran
**Dasar Pemrograman Bahasa C:** Pembelajaran dilakukan secara berkelompok, dimulai dari tingkat dasar (fundamental) hingga pemahaman konsep pemrograman.
